## À propos

Je me reconvertis dans l'analyse de données après plusieurs années de coordination de projets et de photographie en freelance. J'ai toujours travaillé avec des données : bases de familles et de bénévoles, reporting d'indicateurs, suivi clients et facturation. Aujourd'hui, j'en fais mon métier.

## Ma façon de travailler : la data avec l'IA

J'utilise les outils d'IA dans tous mes projets data, et je le revendique. Un data analyst aujourd'hui sait piloter l'IA pour aller plus vite, sans rien lâcher sur la fiabilité.

| Étape | Ce que je fais |
|---|---|
| **1. Question métier** | Je reformule le besoin jusqu'à ce qu'il soit précis et mesurable |
| **2. Contexte** | Je décris à l'IA la structure des données et les règles de gestion |
| **3. Requêtes et code** | Je fais générer le SQL et le Python étape par étape |
| **4. Vérification** | Contrôles de cohérence, recalcul des chiffres clés, valeurs atypiques |
| **5. Esprit critique** | Une corrélation n'est pas une cause, une moyenne peut cacher une exception |
| **6. Automatisation** | Notebooks relançables d'un clic, tableaux de bord alimentés automatiquement |
| **7. Restitution** | Des conclusions claires pour des personnes qui ne sont pas du métier |
