## Ma façon de travailler : la data avec l'IA

J'utilise les outils d'IA dans tous mes projets data, et je le revendique. Aujourd'hui, un data analyst ne se contente plus d'écrire des requêtes : il sait aussi piloter l'IA pour aller plus vite, sans rien lâcher sur la fiabilité. Concrètement, voici comment je travaille :

- **Je pars de la question métier** et je la reformule jusqu'à ce qu'elle soit précise.
- **Je donne le contexte à l'IA** : la structure des données, ce que représente une ligne, les règles de gestion.
- **Je fais générer les requêtes SQL et le code Python**, étape par étape, plutôt que tout d'un bloc.
- **Je relis et je vérifie chaque résultat** : contrôles de cohérence, recalcul des chiffres clés, recherche des valeurs atypiques. C'est l'étape qui fait la différence.
- **Je questionne les conclusions** : une corrélation n'est pas une cause, une moyenne peut cacher une exception.
- **J'automatise ce qui se répète** : notebooks qui se relancent d'un clic, tableaux de bord alimentés automatiquement.
- **Je documente et je restitue** pour des personnes qui ne sont pas du métier.
